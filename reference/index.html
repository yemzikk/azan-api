API reference/Overview

API reference

All endpoints use GET and return JSON from https://api.azantimes.in. Ids are lower case with hyphens. Each endpoint has its own page with a Try it panel.

EndpointDescriptionSize
GET/v2/locations.json
List timetables
Every timetable with its district, school and coordinates156 KB
GET/v2/locations/{id}.json
Get a timetable
One timetable, with the years available1 KB
GET/v2/locations/{id}/timetables/{year}.json
Get a year timetable Most used
Every day of one calendar year43 KB
GET/v2/locations/{id}/timetables/perpetual.json
Get the perpetual timetable
The 366-day table, valid for any year42 KB
GET/v2/index.json
Get API information
Prayer keys, years, links and dataVersion1 KB

How the files fit together

Every file carries links to the next, so you can start at the index and follow them.

Path parameters

idstringrequired

Timetable id from List timetables, for example kuttiady-assembly-constituency.

yearintegerrequired

Calendar year from 2020 to 2031. A new year is added each January.

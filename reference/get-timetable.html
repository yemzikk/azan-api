API reference/Get a timetable

Get a timetable

GET/v2/locations/{id}.json

Returns one timetable with its district, school, source calendar, coordinates and the years available.

Path parameters

idstringrequired

Timetable id from List timetables, for example kuttiady-assembly-constituency.

Returns

A location object, with links to its year files, its perpetual file and its page on the prayer dashboard.

JSON1 KB
Every field is described in Response format

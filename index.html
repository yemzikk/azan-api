Getting started/Introduction

AzanTimes API

A read-only JSON API for Kerala prayer timetables. It covers all 140 Assembly constituencies and 51 regional calendars that masjids follow, for every year from 2020 to 2031. No API key or sign-up is needed.

Authentication

None. Every endpoint is public and read-only, with no API key, token or sign-up. Responses carry these headers:

HeaderWhat it means for you
Access-Control-Allow-Origin: *Call the API directly from a web page on any site.
Access-Control-Allow-Methods: GET, HEAD, OPTIONSRequests are read-only.
Content-Type: application/jsonCheck it before parsing. A missing file can return an HTML page.

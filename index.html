01 / GETTING STARTED

From request to prayer times.

Pick a timetable from the locations list, then request its year. Each year file holds every day, so one request covers a whole year of prayer times.

BASE URLhttps://api.azantimes.in
JavaScript
const base = 'https://api.azantimes.in';
const id = 'kuttiady-assembly-constituency';

// Today's date in Kerala, for example '2026-11-23'.
const today = new Intl.DateTimeFormat('en-CA', { timeZone: 'Asia/Kolkata' }).format(new Date());

const response = await fetch(`${base}/v2/locations/${id}/timetables/${today.slice(0, 4)}.json`);
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const { days, attribution } = await response.json();
const times = days.find((day) => day.date === today);
console.log(times.fajr, times.maghrib); // '05:03' '18:03'
i

Version 2 files are the same every day they are served, so you can cache a year and look up each day locally. The attribution field holds a suggested credit line.

02 / ENDPOINTS

Version 2. Stable files, any year.

All requests use GET and return JSON. Identifiers are lower case with hyphens, for example kollam-assembly-constituency. The full contract is in openapi.json (OpenAPI 3.1).

GET/v2/locations.json

All timetables

Every timetable with its district, school (Shafi’i or Hanafi), source and coordinates. Use the coordinates to suggest the nearest timetable.

object
GET/v2/locations/{id}/timetables/{year}.json

One year

Every day of a calendar year, from 2020 to five years ahead. Dates are ISO 8601 and times are 24-hour.

object
GET/v2/locations/{id}/timetables/perpetual.json

Every year

The 366-day table itself, including 29 February. Use it for any year; skip 29 February outside leap years.

object
GET/v2/locations/{id}.json

One timetable

The same details as the list, for a single timetable, with the years available.

object
GET/v2/index.json

About the API

Prayer keys, available years, links and a dataVersion that changes whenever any timetable is corrected or added.

object

Version 1, still supported

Existing integrations keep working unchanged. Version 1 receives the same corrections and new timetables as version 2.

04 / RESPONSE FORMAT

A familiar shape, every time.

Each timetable file starts with the location, the time zone and an attribution line, followed by days. Times are local to Kerala (Asia/Kolkata, UTC+05:30) and mark the start of each prayer.

05 / INTEGRATION NOTES

A few things to build around.

01

Choose the right timetable

Some places have more than one calendar, and some follow the Hanafi school. Suggest the nearest timetable from its coordinates, keep the source name, and let people choose the one their masjid follows.

02

Cache a year, refresh on change

A version 2 year file does not change from day to day. Cache it, look up each date locally, and refetch when dataVersion in index.json changes.

03

Handle unavailable data

Check the HTTP status before parsing JSON. Missing files can return a 404 or an HTML error page. Keep a helpful fallback in your interface.

04

Respect the local schedule

Timetable times are local to their location. Do not reinterpret them in the device’s timezone. Confirm local mosque timings for congregation times.

06 / USAGE & CREDIT

Free to use. Credit is welcome.

The timetable data is in the public domain under CC0 1.0. Use it in your app, website, masjid display or bot, including paid ones. Credit is not required. If you can show a small credit with a link, it helps people check the times against the calendar they follow, and it helps correct times reach more people.

01

Credit the calendar too

Show the timetable’s source name beside the times. People look for the calendar they follow, and it credits those who prepared it.

02

Use the artwork as supplied

Scale the wordmark and badge to any size. Please keep the letters and colours as they are, so people recognise them.

03

Keep your own name

Your app keeps its own name and look. Present AzanTimes as the source of the times, not as the maker of your app.

04

Tell us what you built

We would like to see it, and we can let you know about changes to the API. Write to developers@azantimes.in.

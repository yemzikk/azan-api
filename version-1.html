Resources/Version 1

Version 1

Supported

Existing integrations keep working unchanged and receive the same corrections and new timetables as version 2. New projects should use version 2.

Endpoints

EndpointReturns
GET/v1/timesheets/index.jsonTimetable names
GET/v1/timesheets/{location}/today.jsonThe day the data was built
GET/v1/timesheets/{location}/month.jsonThat month
GET/v1/timesheets/{location}/year.jsonThat year
GET/v1/timesheets/{location}/all.jsonAll records

Moving to version 2

Each location in locations.json lists its version 1 name as legacyId, so you can map existing settings.

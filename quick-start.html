Getting started/Quick start

Quick start

Show today’s prayer times in three steps. Every endpoint is a static JSON file, so you can open each one in a browser tab before writing any code.

  1. 1

    Pick a timetable

    Fetch the list once. Each entry has an id, district, school and coordinates.

    GET/v2/locations.json
  2. 2

    Fetch the year

    One file holds every day of the year. It stays the same from day to day, so cache it.

    GET/v2/locations/{id}/timetables/{year}.json
  3. 3

    Show today

    Find today’s date in Kerala time in days and read the six times.

    days.find((d) => d.date === today)

Example

The same three steps in your language. Each prints Subh and Maghrib for Kuttiady.

const base = 'https://api.azantimes.in';
const id = 'kuttiady-assembly-constituency';

// Today's date in Kerala, for example '2026-11-23'
const today = new Intl.DateTimeFormat('en-CA', { timeZone: 'Asia/Kolkata' }).format(new Date());

const res = await fetch(`${base}/v2/locations/${id}/timetables/${today.slice(0, 4)}.json`);
if (!res.ok) throw new Error(`HTTP ${res.status}`);

const { days } = await res.json();
const times = days.find((day) => day.date === today);
console.log(times.fajr, times.maghrib);

from datetime import datetime
from zoneinfo import ZoneInfo
import requests

base = 'https://api.azantimes.in'
loc = 'kuttiady-assembly-constituency'
today = datetime.now(ZoneInfo('Asia/Kolkata')).date().isoformat()

res = requests.get(f'{base}/v2/locations/{loc}/timetables/{today[:4]}.json', timeout=15)
res.raise_for_status()

times = next(d for d in res.json()['days'] if d['date'] == today)
print(times['fajr'], times['maghrib'])

import 'dart:convert';
import 'package:http/http.dart' as http;

const base = 'https://api.azantimes.in';
const id = 'kuttiady-assembly-constituency';

// Kerala is UTC+05:30 all year
final now = DateTime.now().toUtc().add(const Duration(hours: 5, minutes: 30));
final today = now.toIso8601String().substring(0, 10);

final res = await http.get(Uri.parse('$base/v2/locations/$id/timetables/${now.year}.json'));
if (res.statusCode != 200) throw Exception('HTTP ${res.statusCode}');

final days = jsonDecode(res.body)['days'] as List;
final times = days.firstWhere((d) => d['date'] == today);
print([times['fajr'], times['maghrib']]);

# Every timetable, with its id and district
curl -s https://api.azantimes.in/v2/locations.json \
  | jq '.locations[] | {id, name, district}'

# One day from a year file
curl -s https://api.azantimes.in/v2/locations/kuttiady-assembly-constituency/timetables/2026.json \
  | jq '.days[] | select(.date == "2026-11-23")'

Use Kerala time to pick the day, not the device’s time zone. Someone travelling abroad still needs the date in Kerala to match the timetable.
